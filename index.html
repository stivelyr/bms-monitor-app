Haitai Battery BLE Protocol Reference

Recovered from Swap Assistant (com.hinergi.swap v1.33.0) decompiled sources, held in reference/gatt/.

Transport

connectGatt(context, autoConnect=false, callback, TRANSPORT_LE) — see reference/gatt/pe0.java:58. Service discovery on GATT_SUCCESS (reference/gatt/xe0.java:94). One-shot timeouts: 10 s connect, 2 s disconnect cleanup, 5 s per read/write/descriptor (reference/gatt/gf0.java:135,243,370,583,689).

GATT profile (service 0x8900)

CharacteristicRole
0x8901Notifications + handshake write (auth)
0x8902Main telemetry frame
0x8903 / 0x8904 / 0x8907Cell voltage frames
0x8905 / 0x8906Fault bit frames
0x8910Control writes (write-type default)

UUIDs are 16-bit IDs expanded at runtime into the Bluetooth base UUID 0000xxxx-0000-1000-8000-00805f9b34fb (reference/gatt/of3.java:30).

Handshake

Enable notifications on 0x8901 (write ENABLE_NOTIFICATION_VALUE to CCCD 0x2902), wait ~500 ms, write 17 bytes of 0xFF (reference/gatt/of3.java:22), wait up to 5 s. Success = non-empty response with response[0] == 0x00.

Cell frames 0x8903/0x8904/0x8907

≥20 bytes; ten u16 big-endian values at 0–1 … 18–19; 0xFFFF = placeholder, skipped; concatenated in read order. Raw counts, never converted to volts.

Control writes (to 0x8910, 3 bytes)

*SetPowerSwitch and DischargeMos map to identical bytes — likely a decompilation artifact; validate on hardware. These bytes physically toggle charge/discharge paths: test only on an authorized pack.
